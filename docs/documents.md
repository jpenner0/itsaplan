# Documents

## Diagrams

A document can contain a [Mermaid](https://mermaid.js.org/intro/) diagram. To insert one, type `/` and choose "Diagram (Mermaid)", or type ` ```mermaid ` to start a code block with the language `mermaid`. The block shows the rendered diagram.

- "Edit code" shows the source with a live preview. "Done" switches back to the diagram.
- Invalid syntax shows the error message from Mermaid.
- Locked, archived, and read-only documents show the diagram and a "Copy code" button.

A diagram is stored as a normal Markdown code block. Export, import, and revision history keep the source. For the diagram syntax, see the [Mermaid documentation](https://mermaid.js.org/intro/).
